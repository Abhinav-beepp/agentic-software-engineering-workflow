# Design Decisions

## FastAPI

FastAPI gives typed request/response validation and automatic OpenAPI documentation while keeping the demo small.

## SQLAlchemy

SQLAlchemy isolates persistence and allows SQLite for the demo with a clear PostgreSQL migration path.

## DAG orchestration

A dependency graph is more expressive than a fixed sequence because API and database planning can be independent after architecture, while implementation waits for both.

## Deterministic validation

Validation of file presence, workflow state, API contract existence, and test-plan existence should not depend on probabilistic model behavior.

## Provider abstraction

The LLM interface permits a real model while keeping local tests and the interview demo deterministic.

## Human approval

The final engineering summary cannot be generated by the workflow when approval is required and absent. This is an actual state transition, not documentation-only language.
